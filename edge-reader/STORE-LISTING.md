# Microsoft Edge Add-ons 发布信息

## 名称

页间 Edge 网页桥接

## 简短说明

把 Edge 中正在阅读的网页小说提取为纯文字，并发送到本机页间阅读器。

## 详细说明

页间 Edge 网页桥接是页间小说阅读器的配套扩展。它可以提取当前小说章节的标题与正文，识别上一章、下一章和目录链接，并提前缓存后两章，让章节切换更流畅。

网页内容只通过 `127.0.0.1` 发送给本机阅读器，不会上传到互联网。扩展不会绕过网站登录、付费、验证码或其他访问限制。

## 权限用途

- 所有网站访问：用户可能在不同小说网站阅读，需要从当前页面提取正文和章节导航。
- 标签页：响应阅读器的章节切换命令，并在当前 Edge 标签页打开目标章节。

## 类别

生产力

## 隐私政策

使用仓库中 `PRIVACY.md` 的内容发布到一个公开 HTTPS 页面，并把该页面地址填入 Partner Center。
