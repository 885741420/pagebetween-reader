# 页间 Edge 网页桥接隐私说明

更新日期：2026-09-03

页间 Edge 网页桥接只在用户主动连接小说页面后读取当前页面的章节标题、正文、上一章、下一章和目录链接，并将这些内容发送到本机 `127.0.0.1:17321` 上运行的页间小说阅读器。

- 不把网页内容、浏览历史或身份信息上传到互联网。
- 不出售、共享或用于广告分析。
- 只访问用户已经能够在 Edge 中正常打开的页面，不绕过登录、付费、验证码或 DRM。
- 为实现快速翻章，会使用当前网站的登录状态在浏览器内预取后两章；缓存保存在本机阅读器中。
- 卸载扩展会移除扩展自身；阅读器保存的本地阅读缓存可由用户卸载阅读器或清除应用数据删除。

扩展需要访问网页内容，是为了提取小说正文；需要标签页权限，是为了在用户操作阅读器时切换上一章、下一章和目录页。
